# Security Policy

## Supported versions

Security fixes target the latest released version of Graphy.

## Report a vulnerability

Do not open a public issue. Use GitHub's private vulnerability-reporting flow from this repository's **Security** tab: [Report a vulnerability](https://github.com/kushalBanda/Graphy/security/advisories/new).

Include affected version, reproduction steps, impact, and any suggested mitigation. The maintainer will acknowledge a valid report, investigate privately, release a fix when needed, then coordinate disclosure with the reporter.

If private reporting is unavailable, do not disclose the vulnerability publicly. Contact the repository owner through the GitHub profile linked from the repository.
