# Code of Conduct

## Our pledge

We want Graphy to be a respectful, constructive place for every contributor. Participate in good faith. Welcome differing views. Focus feedback on ideas and code.

## Expected behavior

- Use welcoming, respectful language.
- Give and accept actionable feedback.
- Assume good intent; ask before escalating disagreement.
- Respect privacy, consent, and contributor time.

## Unacceptable behavior

- Harassment, threats, discrimination, or personal attacks.
- Sexualized language or imagery in project spaces.
- Publishing private information without permission.
- Repeatedly disrupting discussion or ignoring moderator direction.

## Enforcement

The repository owner reviews reports and may remove content, limit participation, or block contributors. Use GitHub's report-content controls for confidential conduct reports. Do not open a public issue for a security vulnerability; follow [SECURITY.md](SECURITY.md).

This Code of Conduct applies in all Graphy project spaces.
